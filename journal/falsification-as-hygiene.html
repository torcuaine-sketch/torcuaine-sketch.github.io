Testing allocation rules

The useful question about an allocation rule is never whether it worked. It is what would have to be true for the rule to be wrong, and whether anyone has seriously tried to show that it is.

Type
Essay
Published
March 2026

A rule that has been tested until it passes is not evidence. It is the residue of a search, and the search itself leaves no trace in the result. So the discipline we run is not confirmation at higher resolution. It is a standing attempt to kill our own ideas, on a schedule, before the market does it for us at a worse price.

Why in-sample success means almost nothing

Any sufficiently flexible rule can be made to fit a finite history. The number of choices available while building one - which window, which universe, which threshold, which handling of the awkward months - is large enough that a good-looking result is the default outcome of effort rather than a discovery about markets. The more work a rule needed in order to look convincing, the less its appearance should be trusted.

This is why the validation window rolls rather than sits still. A rule is re-fitted on information available at each point and then evaluated only on what came next, across a twenty-four month window that moves forward one step at a time. A rule that survives that procedure has at least been asked the right question repeatedly. It has not been proven correct.

Independent review

Three separate models test each allocation before capital is committed. They use different assumptions and test different failure modes.

What each seat on the panel is asked to attack
Line of attackThe questionFailure it is looking for
SpecificationWould a slightly different construction reverse thisA result that depends on an arbitrary choice
RegimeDoes this hold outside the state that produced itA rule fitted to one market condition
MechanismWhat is the reason this should work at allA pattern with no stated cause behind it

A proposal that no seat can damage is treated with more suspicion, not less. In practice an unattackable result usually means the attack was aimed at the wrong thing, or the proposal is so vague that nothing about it is falsifiable.

Pre-committed exits

Every rule that reaches production carries its own exit conditions, written before the position exists. This matters because the moment a position is losing money is the worst possible moment to decide what would justify closing it. Judgement at that point is not judgement; it is the position arguing for its own survival through whoever holds it.

  1. State the falsifier firstWhat observation would mean the rule is wrong. Written down before capital moves, not reconstructed afterwards.
  2. Size to the falsifierThe position is sized so that reaching the exit condition is survivable at the book level, not merely tolerable in isolation.
  3. Execute the exit mechanicallyThe exit is a rule, not a meeting. Overrides are recorded as overrides so the discretion is visible rather than absorbed.
  4. Retire without ceremonyA rule that fails its own falsifier leaves production. It does not get one more quarter to prove itself.

What gets rejected

The great majority of candidate rules do not reach production, and the most common reasons are unglamorous: the result depends on a single stretch of history, the effect vanishes once realistic costs and the five-day exit floor are imposed, the mechanism cannot be stated in a sentence, or the rule is a restatement of exposure the book already carries. None of these are interesting failures. That is rather the point - a process that only rejects for interesting reasons is not rejecting enough.

Scope

Falsification improves the quality of the evidence behind a decision. It does not make the decision correct, and a rule that survives every test can still lose money, including immediately and for reasons no model considered. We describe this process because it is what we actually do, not because it removes risk. It does not.

This note describes internal research and validation process. The window length, cycle stages and panel size describe process design as at March 2026; none of them are performance figures and none imply an investment return. Nothing here is an offer, a solicitation, or investment advice.
